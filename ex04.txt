    Exercício 4. Teste de mesa — if aninhado (1,0 pt)
    Analise o trecho abaixo, que lê dois inteiros a e b :
    1 if (a > b)
    2   if (a % 2 == 0)
    3       printf("A");
    4   else
    5       printf("B");
    6 else if (a == b)
    7   printf("C");
    8 else
    9   printf("D");
    10 if (a = 0)
    11  printf("E");
    12 printf("F\n");
    a) Qual a saída para as entradas (8,3) , (7,3) , (5,5) e (2,9) ?
    b) A qual if pertence o else da linha 4? Justifique e reescreva o trecho usando
    chaves para deixar isso explícito.
    c) A linha 10 contém um erro clássico. Explique o que acontece, por que E nunca
    é impresso e qual o valor de a após essa linha.

---
a) a = 8, b = 3
    if (8 > 3) // VERDADE
        if (8 % 2 == 0) // VERDADE
            PRINTA "A"
    if (a = 0) // Atribui 0 a "a", valor da expressao = 0, logo é FALSO
    PRINTA "F" e quebra linha
    Resultado = "AF"

    a = 7, b = 3
    if(7 > 3) // VERDADE

b) O else da linha 4 pertece ao if da linha 2 (if (a % 2 == 0)).
    Justificativa: O else sempre se associa ao if mais proximo que ainda nao tem else.
    
    if (a > b) {
        if (a % 2 == 0) {
            printf("A");
        } else {
            printf("B");
        }
    } else if (a == b) {
        printf("C");
    } else {
        printf("D");
    }
    if (a = 0) {
        printf("E");
    }
    printf("F\n");

c) Na linha 10, "a = 0" é uma atribuição e não uma comparação, o valor 0 e gravado em "a". A expressao "a" vale 0, em C 0 é tratado como falso, entao o printf("E") nunca e executado. a fica valendo 0 (a = 0).

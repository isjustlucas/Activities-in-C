# C Programming Activities

This repository contains programming activities and exercises developed in the **C programming language** as part of my academic coursework under the guidance of Professor **Ana Carolina Sokolonski Anton**.

The activities focus on developing programming logic, problem-solving skills, and understanding fundamental programming concepts through practical exercises.

**Topics covered:**

- Variables and data types
- Input and output operations
- Conditional statements (`if`, `else`, `switch`)
- Loop structures (`for`, `while`, `do-while`)
- Functions and modular programming
- Arrays and strings
- Pointers and memory management
- Basic algorithms and problem-solving

**Language:** C  
**Instructor:** Ana Carolina Sokolonski Anton
